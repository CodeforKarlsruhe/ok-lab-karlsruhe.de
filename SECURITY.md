# Security Policy

## Supported Versions

This repository deploys continuously from the `main` branch to [ok-lab-karlsruhe.de](https://ok-lab-karlsruhe.de). Security updates apply directly to `main`.

## Reporting a Vulnerability

If you discover a potential security vulnerability in the website, Keystatic CMS integration, or GitHub Actions deployment setup, **please do not report it in a public GitHub issue.**

Instead, please report it privately using one of the following methods:

1. **GitHub Security Advisory:** Submit a private report via the repository's **Security** tab under **Report a vulnerability**.
2. **Email:** Send details to **[info@ok-lab-karlsruhe.de](mailto:info@ok-lab-karlsruhe.de)**.

### What to Include

- A clear description of the issue and potential impact
- Steps to reproduce or proof-of-concept
- Affected URLs, files, or workflow steps

### Response

Reports are reviewed on a volunteer best-effort basis by the OK Lab Karlsruhe maintainers. Please allow reasonable time for investigation and remediation before public disclosure.
