# Code of Conduct

Das OK Lab Karlsruhe (Code for Karlsruhe) ist Teil des bundesweiten Netzwerks **Code for Germany** unter dem Dach der Open Knowledge Foundation Deutschland e.V.

Für alle Beiträge, Issues, Pull Requests und Treffen gilt der gemeinsame Verhaltenskodex von Code for Germany:

- **[Code for Germany — Code of Conduct](https://codefor.de/codeofconduct/)**

Bei Vorfällen oder Fragen erreichst du das Organisationsteam unter **[info@ok-lab-karlsruhe.de](mailto:info@ok-lab-karlsruhe.de)**.
